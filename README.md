# Kerala Trail

A free browser game demo inspired by Kerala road trips. Match animal tiles to earn trip coins, pick a vehicle, and drive across a 3D Kerala map.

## Play

After the first GitHub Pages deployment completes, open:
https://r3275.github.io/Kerala-Trail-Game/

Match animal tiles to earn trip coins, choose **CAR**, **BIKE**, **BUS**, or **AUTO**, then unlock and ride a route. During a ride, use **W / ↑ / ▲** to accelerate, **S / ↓ / ▼** to brake, and **A / D / ◀ / ▶** to steer. Keyboard and touch controls are supported.

The Kerala-trial-6 repository is a GTA V AI-driving project. This browser game does not include that Python model; it uses a similar driving idea with controls adapted to the 3D Kerala map.
